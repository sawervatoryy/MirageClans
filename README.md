# MirageClans v0.1

Современная клановая система для **Paper 1.21.4** (Java 21) по аналогии с pnClans: всё управление строится вокруг
анимированных GUI, гибкой системы ролей и интеграций с Vault, PlayerPoints и PlaceholderAPI.

## Возможности

- Создание, роспуск, приглашения, исключение, передача лидерства, статистика и **топ кланов** (по уровню, очкам, балансу).
- Главное меню с **анимацией** при вводе `/clan` (алиасы `/c`, `/clans`) — предметы появляются волной от центра.
- Переключатель `use-gui` в `config.yml`: можно полностью отключить меню, все команды продолжат работать.
- Настраиваемые **роли** (Лидер, Заместитель, Участник, Новичок + свои) и **матрица прав** в GUI.
- **Friendly Fire** с проверкой владельца снарядов (стрелы, трезубцы, зелья, туманные облака, динамит, питомцы).
- Клановый чат строго через `/cc` — без символов-префиксов в обычном чате.
- Подсветка соклановцев: контурное свечение или цветные ники, с настройкой в меню.
- **Казна** с двумя валютами: Vault (деньги) и PlayerPoints (донат-очки), быстрые кнопки и история операций.
- Общий **склад** (до 54 слотов), вместимость зависит от уровня клана, закрытые слоты — отдельный предмет.
- **Дома** клана с лимитом по уровню и телепортом с задержкой.
- **Уровни и квесты**: общие квесты клана дают опыт и деньги в казну, уровень открывает слоты, дома, склад.
- SQLite (по умолчанию) и MySQL/MariaDB, всё асинхронно.
- Полная интеграция с PlaceholderAPI (включая relational-плейсхолдеры для TAB).

## Требования и установка

| Что | Версия | Обязательно |
|---|---|---|
| Paper | 1.21.4 | да |
| Java | 21 | да |
| Vault + плагин экономики | любая | нет (без него отключается валюта «деньги») |
| PlayerPoints | 3.x | нет (без него отключается валюта «очки») |
| PlaceholderAPI | 2.11+ | нет (без него нет плейсхолдеров) |
| ProtocolLib | 5.3+ | нет (нужен только для режима подсветки GLOW) |

**Установка:**
1. Положите `MirageClans-v0.1.jar` в папку `plugins/`.
2. Запустите сервер. При первом старте Paper **сам скачает** библиотеки HikariCP, sqlite-jdbc и mariadb-java-client
   (серверу нужен доступ к Maven Central). Они указаны в `plugin.yml` в секции `libraries` и в jar не включены.
3. Появится папка `plugins/MirageClans/` с `config.yml`, `lang.yml`, `menus.yml`, `quests.yml`.
4. Настройте конфиги и выполните `/clan reload`.

## Сборка из исходников

```
mvn clean package
```

Готовый jar появится в `target/`. Репозитории (PaperMC, JitPack, PlaceholderAPI, Rosewood, dmulloy2) уже прописаны в `pom.xml`.
`maven-shade-plugin` **не используется** — зависимости подгружает сервер.

## Быстрый старт

1. Игрок вводит `/clan` и жмёт **«Создать клан»**, затем вводит в чат название и тег
   (или командой: `/clan create <название> <тег>`).
2. Приглашает друзей: меню участников → **«Пригласить игрока»** или `/clan invite <ник>`.
3. Друзья принимают: `/clan accept` или через меню **«Приглашения»**.
4. Клан выполняет квесты → получает опыт → растёт уровень → открываются слоты склада, дома и места для участников.

## Команды

### Основные
| Команда | Описание |
|---|---|
| `/clan` | открыть главное меню (если `use-gui: false` — показать справку) |
| `/clan help` | справка |
| `/clan create <название> <тег>` | создать клан |
| `/clan disband confirm` | распустить клан (только лидер) |
| `/clan leave` | покинуть клан (лидер выйти не может) |
| `/clan info [клан]` | информация о клане |
| `/clan members` | список участников |
| `/clan top [level\|points\|balance]` | рейтинг кланов |

### Участники
| Команда | Описание |
|---|---|
| `/clan invite <игрок>` | пригласить (право `INVITE`) |
| `/clan accept [клан]` / `/clan deny [клан]` | принять / отклонить приглашение |
| `/clan kick <игрок>` | исключить (право `KICK`) |
| `/clan promote <игрок>` / `demote <игрок>` | повысить / понизить на одну ступень (право `MANAGE_ROLES`) |
| `/clan setrole <игрок> <роль>` | назначить конкретную роль |
| `/clan transfer <игрок>` | передать лидерство |

### Роли
| Команда | Описание |
|---|---|
| `/clan role list` | список ролей и выданных прав |
| `/clan role create <название>` | создать свою роль |
| `/clan role delete <id>` | удалить роль (участники получат роль по умолчанию) |
| `/clan role perm <id> <право>` | включить/выключить право у роли |

### Казна, склад, дома
| Команда | Описание |
|---|---|
| `/clan deposit <money\|points> <сумма>` | внести в казну |
| `/clan withdraw <money\|points> <сумма>` | снять из казны |
| `/clan balance` | баланс казны |
| `/clan history` | история операций казны |
| `/clan storage` | открыть общий склад |
| `/clan sethome [имя]` | установить дом клана |
| `/clan home [имя]` | телепорт на дом (если дом один — имя можно не указывать) |
| `/clan delhome <имя>` | удалить дом |
| `/clan homes` | список домов |

### Прокачка и настройки
| Команда | Описание |
|---|---|
| `/clan quests` | квесты клана |
| `/clan level` | информация об уровне |
| `/clan upgrade` | повысить уровень (только при `leveling.mode: MANUAL`) |
| `/clan ff [on\|off]` | дружеский огонь |
| `/clan glow <off\|glow\|name>` | режим подсветки соклановцев |
| `/clan glow color <цвет>` | цвет подсветки |

### Чат и админ
| Команда | Описание |
|---|---|
| `/cc <сообщение>` | одно сообщение клану |
| `/cc` | включить/выключить режим кланового чата (все сообщения идут клану) |
| `/clan reload` | перезагрузить конфиги (право `mirageclans.admin`) |

В режиме `use-gui: false` команды `members`, `top`, `homes`, `quests`, `level` выводят данные текстом, а не открывают меню.

## Меню (GUI)

| Меню | Что делает |
|---|---|
| **Главное** | входная точка, анимированное; вариант для игрока без клана: создать, приглашения, топ |
| **Участники** | ЛКМ — повысить, ПКМ — понизить, Shift+ЛКМ — исключить, Shift+ПКМ — передать лидерство; кнопка приглашения |
| **Роли и права** | список ролей → редактор: переключатели прав, приоритет (ЛКМ +5 / ПКМ −5), переименование, удаление |
| **Казна** | баланс, быстрые суммы (ЛКМ — внести, ПКМ — снять), своя сумма через чат, история |
| **История казны** | кто, сколько и когда (грузится асинхронно из БД) |
| **Склад** | общий инвентарь клана |
| **Дома** | ЛКМ — телепорт, Shift+ПКМ — удалить, кнопка установки дома |
| **Квесты** | вкладки «ежедневные / еженедельные», прогресс-бары, награды, время до обновления |
| **Уровень** | текущий и следующий уровень, кнопка улучшения |
| **Топ** | вкладки по уровню / очкам / балансу |
| **Настройки** | урон по своим, режим и цвет подсветки |
| **Приглашения** | ЛКМ — принять, ПКМ — отклонить |

Всё меню настраивается в `menus.yml`: слоты, материалы, названия, описания, фон. Ввод текста (название клана, сумма, ник)
происходит через чат; чтобы отменить ввод, напишите `отмена`.

## Роли и права

Роли по умолчанию (настраиваются в `config.yml → roles.templates`):

| Роль | Приоритет | Права по умолчанию |
|---|---|---|
| Лидер | 1000 | все (неизменяемая) |
| Заместитель | 80 | все |
| Участник | 50 | внесение в казну, склад, телепорт на дом |
| Новичок | 10 | внесение в казну, телепорт на дом |

Новые участники получают роль из `roles.default-role` (по умолчанию `NEWBIE`).

**Список прав:**

| Право | Что даёт |
|---|---|
| `TREASURY_DEPOSIT` | вносить в казну |
| `TREASURY_WITHDRAW` | снимать из казны |
| `STORAGE` | открывать общий склад |
| `HOME_TELEPORT` | телепортироваться на дома |
| `HOME_MANAGE` | ставить и удалять дома |
| `KICK` | исключать участников |
| `INVITE` | приглашать игроков |
| `PVP_MANAGE` | включать/выключать урон по своим |
| `MANAGE_ROLES` | повышать/понижать, создавать и редактировать роли |
| `UPGRADE` | повышать уровень клана |
| `SETTINGS` | менять подсветку соклановцев |

**Иерархия:** действовать на участника или роль можно, только если ваш приоритет **выше**. Заместитель не может исключить
другого заместителя, а повысить участника можно максимум до роли ниже своей.
Распустить клан и передать лидерство может только лидер.

## Дружеский огонь (PvP)

Переключатель находится в меню «Настройки» или командой `/clan ff`. Когда урон по своим **выключен**, защита работает для:

- удара рукой и оружием;
- стрел и арбалетных болтов, трезубцев и других снарядов (проверяется **владелец снаряда**);
- брошенных и туманных зелий (вредные эффекты не применяются к соклановцам);
- подожжения, динамита (TNT, активированный игроком) и приручённых питомцев.

Список «вредных» эффектов зелий задаётся в `config.yml → friendly-fire.harmful-effects`.

## Клановый чат

- `/cc <сообщение>` — одно сообщение всему клану.
- `/cc` без аргументов — включить режим, в котором **все** ваши сообщения идут в клановый чат; повторный `/cc` выключает.
- В обычном чате никаких префиксов-символов нет.

Формат задаётся в `config.yml → chat.format`, доступны `{tag}`, `{clan}`, `{role}`, `{player}`, `{message}`.
Текст сообщения игрока выводится как обычный текст (цветовые коды в нём не работают).

## Подсветка соклановцев

Режим выбирается в меню «Настройки» (или `/clan glow`):

| Режим | Как работает |
|---|---|
| **OFF** | выключено |
| **GLOW** | контурное свечение, видно **только соклановцам**; нужен ProtocolLib (пакеты метаданных) |
| **NAME_COLOR** | цветные ники |

Цвет выбирается из списка `config.yml → glow.colors`.

**Про NAME_COLOR:** встроенный вариант красит ники через команду scoreboard, и это видят **все** игроки. Если нужна окраска
только для соклановцев (и вы используете TAB), отключите встроенный вариант (`glow.name-color-team: false`) и используйте
relational-плейсхолдер `%rel_mirageclans_color%`.

## Казна

- Две валюты: **Vault** (деньги) и **PlayerPoints** (очки). Каждую можно отключить: `treasury.money-enabled`, `treasury.points-enabled`.
- Быстрые суммы настраиваются в `treasury.quick-amounts`.
- Каждая операция записывается в историю: игрок, действие, сумма, валюта, время. Старые записи удаляются через
  `database.history-keep-days` дней.
- **Защита от дюпов:** операции с балансом атомарные; при внесении деньги сначала списываются у игрока и только потом
  зачисляются в казну, при снятии — наоборот. Если экономика вернула ошибку, операция откатывается.
- Награды за квесты тоже попадают в казну и видны в истории как «награда за квест».

## Общий склад

- У клана один общий инвентарь на 54 слота. Все участники работают с одними и теми же слотами, поэтому дюп между
  игроками невозможен.
- Доступно столько слотов, сколько указано для уровня клана (`leveling.levels.<N>.storage-slots`). Остальные заняты
  предметом-заглушкой (настраивается в `menus.yml → menus.storage.items.locked`) и недоступны для кликов.
- Содержимое сохраняется при закрытии склада последним игроком, автоматически раз в `storage.autosave-seconds`
  секунд и при выключении сервера. Запись в БД идёт асинхронно.
- Доступ определяется правом `STORAGE`.

## Дома

- Установка: `/clan sethome [имя]` или кнопка в меню (право `HOME_MANAGE`).
- Количество домов ограничено уровнем клана (`max-homes`). Повторная установка с тем же именем перезаписывает дом.
- Телепорт: задержка `homes.teleport-delay-seconds` секунд, отменяется при движении (`homes.cancel-on-move`).
- Миры, в которых нельзя ставить дом: `homes.blacklisted-worlds`.

## Уровни и прокачка

Уровни задаются в `config.yml → leveling.levels`. Пример:

```yaml
leveling:
  mode: AUTO
  levels:
    1: { xp-required: 500, upgrade-cost: 0, max-members: 5, storage-slots: 9, max-homes: 1 }
    2: { xp-required: 1200, upgrade-cost: 5000, max-members: 8, storage-slots: 18, max-homes: 1 }
```

| Параметр | Значение |
|---|---|
| `xp-required` | опыт для перехода **с этого** уровня на следующий (на последнем уровне — `0`) |
| `upgrade-cost` | стоимость из казны при ручном повышении |
| `max-members` | максимум участников на этом уровне |
| `storage-slots` | сколько слотов склада открыто (0–54) |
| `max-homes` | максимум домов |

**Режимы:**
- `AUTO` — уровень растёт сам, как только набран опыт; излишек переносится.
- `MANUAL` — опыт копится, повысить уровень нужно кнопкой «Улучшить» или `/clan upgrade`; при этом списывается опыт
  и `upgrade-cost` из казны (нужно право `UPGRADE`).

Опыт клан получает только за выполнение квестов.

## Квесты

Квесты общие: прогресс считается суммарно по всему клану. Описываются в `quests.yml`.

```yaml
quests:
  daily_zombies:
    period: DAILY              # DAILY | WEEKLY
    type: KILL_MOB             # тип квеста
    target: ZOMBIE             # цель (или targets: [A, B]); ANY — любая
    amount: 100                # сколько нужно
    min-level: 1               # с какого уровня клана доступен
    name: "&fОхота на зомби"
    description:
      - "&7Клан вместе убивает зомби."
    icon: ZOMBIE_HEAD
    rewards: { xp: 50, money: 500, points: 0 }
```

**Типы квестов:**

| Тип | Что считается | `target` |
|---|---|---|
| `KILL_MOB` | убийства мобов | тип существа (`ZOMBIE`) или `ANY` |
| `KILL_PLAYER` | убийства игроков чужих кланов | не нужен |
| `BREAK_BLOCK` | сломанные блоки | материал (`DIAMOND_ORE`) или `ANY` |
| `TREASURY_DEPOSIT` | деньги, внесённые в казну | не нужен |
| `PLAYTIME` | наигранное время участников, **в минутах** | не нужен |

**Обновление:** время и часовой пояс в `reset.timezone` / `reset.hour`, день недели для еженедельных — `reset.weekly-day`.
При смене периода прогресс сбрасывается.

**Награда:** клановый опыт (`xp`) и средства в казну (`money`, `points`).

**Защита от накрутки:** убийства игроков не засчитываются между соклановцами, один и тот же убийца/жертва — не чаще раза в
`settings.kill-player-same-victim-cooldown-seconds` секунд; в креативе добыча блоков не идёт в зачёт.
Блоки, поставленные игроками, отдельно **не отслеживаются**.

## Плейсхолдеры PlaceholderAPI

Идентификатор расширения: `mirageclans`. Регистрируется автоматически, если установлен PlaceholderAPI.

| Плейсхолдер | Значение |
|---|---|
| `%mirageclans_name%` | название клана |
| `%mirageclans_tag%` | тег клана |
| `%mirageclans_role%` | роль игрока (с цветом) |
| `%mirageclans_leader%` | ник лидера |
| `%mirageclans_level%` | уровень клана |
| `%mirageclans_xp%` | текущий опыт |
| `%mirageclans_xp_needed%` | опыт, нужный для следующего уровня |
| `%mirageclans_xp_left%` | сколько опыта осталось до следующего уровня |
| `%mirageclans_xp_percent%` | прогресс до следующего уровня, % |
| `%mirageclans_balance%` | баланс казны (деньги) |
| `%mirageclans_points%` | баланс казны (очки) |
| `%mirageclans_members_online%` | участников онлайн |
| `%mirageclans_members_total%` | участников всего |
| `%mirageclans_members_max%` | максимум участников на текущем уровне |
| `%mirageclans_friendly_fire%` | урон по своим: вкл/выкл |
| `%mirageclans_homes%` | количество установленных домов |
| `%mirageclans_has_clan%` | `true` / `false` |

**Relational (для TAB, видны по отношению к другому игроку):**

| Плейсхолдер | Значение |
|---|---|
| `%rel_mirageclans_color%` | код цвета ника соклановца (только в режиме NAME_COLOR), иначе пусто |
| `%rel_mirageclans_same%` | `true`, если игроки в одном клане |

**Игрок без клана:** значения берутся из `config.yml → placeholders.no-clan.<идентификатор>`. Например, `name: "&7Нет клана"`
выведет серый текст вместо названия. Не заданные идентификаторы дают пустую строку.

**Примеры для TAB / Scoreboard:**
```
Клан: %mirageclans_name% [%mirageclans_tag%]
Уровень: %mirageclans_level% (%mirageclans_xp%/%mirageclans_xp_needed%)
Казна: %mirageclans_balance%
Онлайн: %mirageclans_members_online%/%mirageclans_members_total%
```
Ник соклановца цветом (TAB, `tagprefix`): `%rel_mirageclans_color%`.

## База данных

```yaml
database:
  type: SQLITE        # SQLITE | MYSQL | MARIADB
  sqlite-file: "clans.db"
  host: "localhost"
  port: 3306
  name: "mirageclans"
  user: "root"
  password: ""
  use-ssl: false
  pool-size: 6
```

- SQLite хранится в `plugins/MirageClans/clans.db`.
- Для MySQL и MariaDB используется драйвер MariaDB Connector/J (работает с обоими серверами); базу нужно создать заранее.
- Таблицы создаются автоматически: `mc_clans`, `mc_members`, `mc_roles`, `mc_homes`, `mc_quests`, `mc_storage`, `mc_treasury_log`.
- Данные кланов целиком держатся в памяти, а в БД пишутся асинхронно. До окончания загрузки при старте команды отвечают
  сообщением «данные загружаются».

## Архитектура

```
org.github.sawervatoryy.mirageClans
├─ MirageClans            главный класс, жизненный цикл
├─ config/                ConfigManager, Settings, Lang, MenuConfig, ButtonDef
├─ model/                 Clan, ClanRole, ClanMember, ClanHome, QuestProgress, TreasuryEntry, ClanPermission, GlowMode
├─ storage/               Database (HikariCP), ClanRepository (всё в отдельном потоке)
├─ manager/               Clan/Treasury/Level/Storage/Home/Quest/Chat/Invite/Prompt/Glow
├─ gui/                   Menu (база), GuiManager, GuiListener
│  └─ menu/               Main, Members, Roles, RoleEditor, Treasury, History, Homes, Quests, Levels, Top, Settings, Invites, Confirm
├─ listener/              Chat, Player, FriendlyFire, Quest
├─ command/               ClanCommand (с автодополнением), ClanChatCommand
└─ hook/                  VaultHook, PointsHook, PapiExpansion, ProtocolGlow
```

Принципы:
- Тяжёлые операции (запросы к БД, запись склада) **не выполняются в главном потоке**: для БД работает отдельная
  однопоточная очередь, поэтому порядок записей сохраняется.
- Казна, опыт и уровень защищены монитором клана, коллекции — потокобезопасные (`ConcurrentHashMap`).
- Сериализация `ItemStack` склада делается в главном потоке (API Bukkit не потокобезопасен), сама запись — асинхронно.
- Строки, цвета и настройки не хардкодятся — всё в конфигах.

## Частые вопросы и проблемы

**Плагин не включается, в консоли ошибка БД.** Проверьте `database.*` в `config.yml`. Для MySQL/MariaDB база должна
существовать, а пользователь иметь права на неё.

**Сервер не скачал библиотеки.** Нужен доступ к Maven Central при первом запуске. На хостинге без интернета положите
`HikariCP`, `sqlite-jdbc` и `mariadb-java-client` в classpath сервера вручную.

**Не работает валюта «деньги»/«очки».** Установите Vault с плагином экономики / PlayerPoints. Без них соответствующая
валюта в казне недоступна (будет сообщение об ошибке экономики).

**Не светятся соклановцы.** Режим GLOW требует ProtocolLib. Без него используйте NAME_COLOR.

**Плейсхолдеры показывают `%mirageclans_...%`.** Установите PlaceholderAPI и перезапустите сервер; проверить регистрацию
можно командой `/papi list`.

**Квест не засчитывает прогресс.** Проверьте `min-level` (клан должен быть не ниже), тип и `target` (названия в верхнем
регистре, как в Bukkit: `ZOMBIE`, `DIAMOND_ORE`) и то, что игрок не в креативе.

**Как отключить меню?** `use-gui: false` в `config.yml` и `/clan reload`.

**Как изменить любой текст?** `lang.yml` (сообщения) и `menus.yml` (меню). После правок — `/clan reload`.
